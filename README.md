# Project Exporter

Расширение для браузера, которое экспортирует проект из редактора [boonan.io](https://boonan.io/) одним zip-архивом: все файлы проекта (по websocket) плюс ассеты.

## Установка

1. Скачайте последний архив `release.zip` из раздела [Releases](https://github.com/Ku6epXBOCTuK/export-game-data/releases) и распакуйте его в отдельную папку.
2. Откройте в браузере страницу `chrome://extensions` (подойдёт Chrome, Edge, Brave, Arc и другие Chromium-браузеры).
3. Включите «Режим разработчика» (переключатель в правом верхнем углу).
4. Нажмите «Загрузить распакованное расширение» и выберите папку, куда вы распаковали архив.

## Использование

1. Откройте свой проект в редакторе: `https://boonan.io/project/...`
2. Нажмите на иконку расширения **Project Exporter** на панели браузера.
3. Нажмите кнопку экспорта и дождитесь завершения — расширение скачает zip-архив со всеми файлами проекта и ассетами.

## Требования

- Chromium-браузер с поддержкой Manifest V3 (Chrome 88+).
- Вы должны быть авторизованы в boonan.io и иметь доступ к экспортируемому проекту.
